# wca-ai-tool-s11_team_victors
# RUPSA SACCO AI Assistant

An intelligent AI assistant that helps members and prospective members access accurate RUPSA SACCO information using Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs).

---

## Project Objectives

- Provide instant answers to SACCO-related questions.
- Retrieve information from official RUPSA SACCO documents.
- Generate accurate and context-aware responses.
- Reduce the time spent searching through manuals, policies, and FAQs.

---

## Features

- Retrieval-Augmented Generation (RAG)
- Intelligent document search
- Conversation memory
- Context-aware responses
- PDF knowledge base
- Secure API key management using environment variables

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

### 4. Create your environment file

Copy:

```
.env.example
```

to

```
.env
```

and update the required environment variables.

### 5. Install dependencies

```bash
pip install -r requirements.txt
```
